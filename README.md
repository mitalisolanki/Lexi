
# Lexi — Your Daily Vocabulary Companion

Lexi is a daily vocabulary-learning web application designed to help people expand their vocabulary one word at a time.

The goal is simple: learn one new word every day and build a consistent learning habit.

## Features

### 1. Daily Word
Discover a new word every day with its meaning, pronunciation, example sentence, and synonyms.

### 2. Personalized Vocabulary
Explore words based on different difficulty levels and categories.

### 3. My Vocabulary
Save your favourite words and revisit them whenever you want.

### 4. Consistency Tracker
Track your learning days, current streak, longest streak, and learning history.

1. Download or clone this repository.
2. Open the Lexi project folder.
3. Double-click `index.html`.
4. Start learning new words!
